# Screen Time Analysis Project

This project analyzes screen time and app usage data to understand user productivity patterns and app usage behaviors.

## Features

- Data cleaning and preprocessing
- Productivity analysis
- Visualization of screen time patterns
- User categorization based on productivity
- YouTube usage analysis

## Requirements

- Python 3.x
- pandas
- numpy
- matplotlib
- seaborn

## Installation

1. Clone the repository:
```bash
git clone [your-repository-url]
```

2. Install required packages:
```bash
pip install -r requirements.txt
```

## Usage

Run the main analysis script:
```bash
python screen_time_analysis.py
```

## Data

The project uses a screen time app usage dataset that includes:
- User ID
- Date
- App name
- Category
- Screen time (minutes)
- Number of launches
- Interactions
- Productivity indicators
- YouTube metrics (views, likes, comments)

## Visualizations

The script generates three main visualizations:
1. Distribution of productive screen time ratio
2. Distribution of users by productivity category
3. Average screen time by productivity category
